README

HOME hero screen: 16 horizontal bars = the 16 tracks across all 64 steps of the pattern. Each bar lights from its own loop_start for loop_len steps — unequal windows & divisions drift apart and re-align at LCM. That visible drift is the product.

Drums (trk0-2, GM ch10) · bass (trk3, prog38) · lead (trk4, prog81) as the default demo. Click bars in SEQ view to toggle steps; sliders morph the selected track's window live (K3/K4 semantics from spec 02 §2.1). WebMIDI out when a device/DAW is connected — the byte stream is the same one the FM-1 firmware will emit (golden hash 5828982717F322ED over 20 s of the demo, byte-identical host C and browser wasm).
