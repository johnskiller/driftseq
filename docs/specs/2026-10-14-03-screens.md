## 1. HOME 总览（GRID 模式主屏）——**"漂移可视化"hero 屏**

16 条横向 loop bar 叠满主区（16×12px=192 + 8px 间隙）：

```
 TRK  LOOP LEN  ┌──────────────────────────────┐
 01   64  U     │██▓▓▓▓▓▒░░░░░░░░░░░░░░░░░░░░░░│▌← 16 步鼓，playhead 慢
 02   12  B     │▌███░░░░░░░░░░░░░░░░░░░░░░░░░░│← 12 步 bass，playhead 快
 03   48  G     │░░░░░▌████████████████░░░░░░░░│← 48 步 pad
 04   16  U     │░░░░░░░░░░░░░▌░░░░░░░░░░░░░░░░│
 ...
 16   32  G     │░░░░░░░░░░░░░░░░░░░░░░░░░▌░░░░░│
```

- 每行一条 bar 代表**该轨自己 loop 的一整圈**（bar 宽度 = 该轨 loop_len 的归一化，不等长 → 不同填充速率）
- `▌` = playhead；**不同轨的 playhead 逐渐错位 = 相位漂移，直接看见**（支柱 2 的落地）
- 左端：轨号(2位) + loop_len(2位) + route 字形（**A**=all **B**=ble **U**=usb）；行可点选（SELECT 循环 / 黑键区点击）
- 选中行高亮；mute 的轨变暗 + 加 `M`
- **这屏不画 step 细节**，只画 16 条相位——它是"全局状态"，不是"编辑工具"
- 顶栏不放模式字（GRID/PLAY），屏内容本身自明；顶栏 = `TRK nn │ PTN nn │ BPM`，右侧角标 = 选中轨
  loop_start 读出 `S nn`（绿色）——K3 拧动时亮带在动，角标给数字锚点（"确切位置"）
- **纵向预算恰满**：20px 顶栏 + 16×12px 行 + 20px 底栏 = 240px；HOME 不设额外读出行
  （曾试过 S/L 独立行，16 号轨被挤出屏，废）——LEN 已在每行行首，不重复显示选中轨 LEN

### 2.0 步录入 = 常态，无进出（rev.5；rev.11 = 覆盖制）

GRID 主页永远处于 step-entry 语义：cursor 常驻、弹键即写、K1 即移动——无"模式进出"
（~~ENV+LFO 同按进出~~作废）；实时录音 = REC 键 arm，与步录入并行不悖：

- **弹键 = 定义 cursor 步的内容并试听**（rev.11 **覆盖制**，John：同位置的录入动作应该是
  覆盖）：单键 = 该步 := {该音}；同时按多键（≤4）= 该步 := {和弦}——**一次按键即该步的
  全部内容**，已有内容的步再弹 = 整体改写（不是追加）；rest 步弹键 = 改写并复活（en=1）。
  一次按 >4 键 = 拒绝（LED 闪）
- 全部松开后 cursor 自动前进一格（QY 行为；st64 处停住不回绕）
- **黑键**：键床音域内 = 键盘黑键（升降号，弹键写入含黑键音）；GLO 长按+黑键 = 第二层修饰排（02 §1）
- **loop 窗口手势（rev.11 定稿）**：**GLO+K1 = START、K2 = LEN**——64 步全程可达；
  ~~GLO+单击两点~~**作废**（取点只能在当前页 16 步内，跨页窗口设不了，John：鸡肋；×16 快进
  同批让位，见 §2.3）。屏上反馈不变：窗口外 dim、起点实竖标、本体亮带
- **live 窗口变形**：拧 K2 改 len 即时生效（全 notes-safe——窗口收缩越过的已响音走完各自
  gate，不发 note-off 断奏）；engine 侧 = 纯参数读，天然确定性
- **回改工作流（rev.11，OCT 键簇上完成——GLO+OCT−/OCT+ 物理相邻）**：修改 = **GLO+OCT−**
  （回退一格）→ 重弹（覆盖制改写）；清除 = **GLO+OCT−** → **GLO+OCT+**（rest，en=0 静默
  可复活）；跳过空步 = K1 右旋（空格无标记）。~~同音重按 = 删除~~随覆盖制作废——GRID 删音
  = rest（ voices 保留）；要真删 voice 去 EDIT 页

### 3.1 鼓轨手势（808 心智；与 melodic §2.3 完全分开，不互换）

**drum 轨**（键床 = 鼓机面板：黑键选鼓、白键 toggle 该鼓发音位）：

| 手势 | 动作 |
|---|---|
| 黑键 | **选鼓**（drumSel；白键 toggle 的对象跟着变）——不移动 cursor |
| 白键 | toggle 当前选鼓在该格的 on/off——**编辑动作，不是选择** |

| EDIT 页 OCT−/OCT+ | cursor 后退/前进一格（同 melodic） |
| EDIT 页内白键 | 试听当前选鼓（不入 voice——写入只发生在 GRID toggle） |
- 分开的理由：melodic 键床 = **纯音高**（移动/写入由旋钮+弹键分工，钢琴心智），drum 键床 =
  **乐器选择+开关**（808 心智）——两套肌肉记忆都成立，但**不互换**；cursor 在 drum 轨退居
  "EDIT 细编的定位器"，GRID 日常编辑（铺/删鼓点）完全绕开它
- EDIT 页对 drum 轨显示同一张 voice 卡片列表（该步全部鼓音各一行），K1 COND/K4 PROB 同语义；
  K2 GATE/K3 VEL 作用于活动 voice（= 屏上高亮的那行鼓音）

## 4. EDIT 步细编（EDIT 键进入；对象 = 选中步 = MELODY/DRUM GRID 黄框格 / STEP-ENTRY cursor 格）

进入即锁定"选中步"；无选中步时显示 cursor 步。主区 = 该步的 **voice 卡片列表**（≤4）：

```
┌──────────────────────────────────────────────────┐
│ EDIT TRK 05 · st19  Cmaj7                        │ 顶栏16px（角标=和弦名/单音名/鼓缩写，st1 起）
├──────────────────────────────────────────────────┤ y=16
│ v1 ○ C3  048        V90 G1.00          [活动卡]  │ 每 voice 一张卡（活动卡黄描边）：
│ v2 ● E3  052        V84 G0.50                   │ **按音高升序**（rev.11，高音在上）
│ v3 ○ G3  055        V90 G2.00                   │ ▶=发声中 ●=rest静默 ○=on
│ v4 ─ 空 (弹键加入；满槽时弹键=替换 v4)           │ K1 改音高不重排（就地保留）
├──────────────────────────────────────────────────┤ y=216
│ PIT v1 GAT 1.00 VEL 90 PRB 100%         r8 10-16 │ 底栏（作用于活动 voice）
│ K1 pit K2 gat K3 vel K4 prob SEL=v              │ cond=GLO 长按+K1
└──────────────────────────────────────────────────┘ y=240
```

- **输入（rev.8/rev.11）**：任意键 = 按键音高弹入并激活——不再限于黑键；鼓轨走 GM 鼓表映射
- **删除 voice（rev.11 三条路，John：同音重弹之外最好也有别的删法）**：
  1. **同音重弹**（最快：先 SELECT 拧到目标卡 → 重弹同音 = 删）；
  2. **活动卡直接删**：SELECT 拧到目标卡 → **GLO+K2**（删除活动卡 voice）——不用记得音高；
  3. **rest 化**：GLO+K4（不删数据，en=0 静默保留，GRID 屏显空心线，可复活）——
     "删显示"与"删数据"分离，误删可逆
- **voice 排列（rev.11 John 提问 → 定稿）**：
  - **主排列 = 音高升序**（高音在上）——与 GRID 横线渲染（§2.1"按音高排序"）同序，两页互认；
    步录入弹进来的和弦（无序）进 EDIT 即按音高归位；顶栏 title 显示**和弦名**（如 `Cmaj7`，
    v1.1 先显示音名列表，和弦识别后补）
  - **手工改动保持**：EDIT 内 K1 改音高后**就地保留排序位**（不重排）——用户刚调过的音
    突然跳位会打断定位感；下次"外来变更"（重新进入 EDIT / GRID 重弹覆盖）时再归位重排
  - **voice 槽 = 优先级**（John 提：poly budget 不够时谁让路）：**v1 > v2 > v3 > v4**——
    排列位即优先级，低音优先（bass/根音在 v1）；引擎 voice steal（01 引擎层复音裁剪）
    按此序，K3 VEL 同值时 v4 先被裁
  - **满槽写入（4/4 时弹新音）**：默认行为 = **抢占 v4**（最低优先级槽）——屏上 v4 卡
    反显提示"被替换"，试听即确认；v4 是 last-resort 不是静默丢弃。想精确控制就先删后加

### 4.1 进入/离开与选中步的来源

- **EDIT 键 toggle**：SEQ/任意页 → EDIT；再按回 SEQ。屏身份自明（无模式字）
- **EDIT 永远有对象**：cursor 常驻单值（内部 0..63，初始 0，永不空；**屏显一律 st1–st64**，
  rev.9 John：0 起点是程序员习惯，音乐人数步从 1 起），进入 EDIT 即编辑 cursor 所指步——
  无需先"选中"（John：既然始终有 cursor，cursor 位置就算选中）。melodic/drum 的差别只在
  **cursor 怎么移动**（两张表：§2.3 / §3.1），选中语义本身两轨型一致
- **"选中" = cursor（John 定：始终有 cursor，cursor 位置即选中）**：无独立选中态——cursor
  是常驻单值（0..63，初始 0），任何时刻 EDIT 都有明确对象，**不存在"未选中"空态**；SEQ 与
  EDIT 共享同一 cursor（一个状态两个视图）。melodic/drum 的差别只在**cursor 怎么移动**，
  不在选中语义本身（详见 §2.3 / §3.1 两张表）：
  - melodic：**K1 = cursor 轴**（GLO 长按+K1 = ×16 快进）——白键只当音高键，不参与选择；
  - drum：屏上点 lane 格 = cursor 跳格（白键是编辑不是选择），黑键选鼓不动 cursor；
  - **OCT± 语义收口**（rev.7）：GRID 步录入 = **键床音程移位 ±12**（弹键音域 F3–G5 的硬约束）；
    PLAY = octave shift；EDIT 页 = cursor 前进/后退一格；键床翻页降级为 GLO 长按+OCT±
- **弹键（EDIT，melodic）**= 弹入新 voice 占空槽并**按音高排序插入**（rev.11）；
  同音重弹 = 删除；drum 轨的写入只发生在 GRID toggle（§3.1），EDIT 页白键 = 试听当前选鼓
- 白键（melodic，EDIT 页）= 试听 v0（不出写入手势，防止误触破坏）

### 4.2 四张 voice 卡与两颗旋钮的分工（SELECT 定对象，K1–K4 改参数）

- **SELECT 拧 = 切活动 voice**（v1↔v2↔v3↔v4 循环，活动卡反白）——SELECT 在 GRID 管轨、
  在 EDIT 管 voice，都是"选对象"职责；EDIT 页**不占 SELECT**（轨选择退场：已进细编，改轨
  按 SEQ 回去）
- **K1–K4 作用于活动 voice**（PROB 例外 = 步级）：
  - **K1 = PITCH**：活动 voice 音高 ±半音（不循环节制 0..127 端点死停）；比"退回 GRID 重弹"
    快，microtonal 微调也走这里
  - **K2 = GATE**：×0.25 步（0.25..8.00，∞ 见 §4.3 前 GATE 说明）
  - **K3 = VEL**：1..127
  - **K4 = PROB**：0..100% 步级（prob 属 step 不属 voice，01 §2）
- **GLO 长按+K4 = rest/tie 三态循环**（rev.7 自 GRID OCT+ 迁入）：按 1 下 = rest（en=0 静默
  保留， voices 不删）、2 下 = tie（gate=0xFF 延音线，01 §2 引擎既有值的唯一输入口）、
  3 下 = 复原；**microstep（开始点偏移，John 提）排在其后**：v1 引擎无此字段——v1.1 候选
  （`ds_note` 加 `offset` u8，humanize/flam 用），落引擎前屏显占位 `MS ±0`，届时 GLO+K4
  变四态循环（rest→tie→microstep→复原）
- **删除 voice**：三条路（见上"删除 voice"节）——同音重弹 / SELECT 定卡 + GLO+K2 真删 /
  GLO+K4 rest 化（可逆）
- 屏上第 4 卡永远显示 v4 或"空"——空卡提示"弹黑键可加"；黑键弹入 = 加 voice 并立即成为
  活动 voice（接着拧 K2/K3 直接细调它）

- GATE 单位 = 本轨 division 步（`gate in steps of this track's division`，01 §2）——
  屏显换算好的小数，拧 1 格 = +0.25 步；`0xFF=until next event` 显示为 `∞`（live morph 时可用）
- cond 与 PROB 的判定顺序见 01 §4（cond 不过 = 整步静默；prob 在 cond 通过后独立掷骰）

### 4.3 cond 大字区（GLO 长按+K1 拧动时的反馈）

- **cond 从底栏 K1 让位给 PITCH**（rev.6）：cond 走 **GLO 长按+K1**（步级枚举不常用，
  修饰层正合适）；拧动时右侧 1/3 屏放大显示 11 态名 + 序号（`4/11 EVERY3`），停止 1s 缩回
  常显——唯一需要"放大反馈"的枚举参数

## 7. PLAY 模式（演奏）

- 顶栏同，模式=`PLAY`
- **键床 = 原生钢琴**：白键 = 自然音（F3–G5），黑键 = 升降号——不重映射（FM-1 本来身份）；
  OCT−/OCT+ = octave shift（本职责）；按键直接出声（GM 或 USB，看选中轨 route），REC armed
  时写入选中轨
- 可选 scale 模式 = **GLO 长按+SEL**（v1.1：白键归音阶、黑键=和弦，CTL-1 验证过的交互）
- 主区：**选中轨的单条大 loop bar**（放大版 hero，只 1 轨，含 step 刻度）+ 上方当前弹奏的
  note 名滚动
- 底栏 4 框（演奏绑定）：`CC1`(K1) `CC2`(K2) `CC3`(K3) `CC4`(K4)；live 窗口变形见 §2.0
- REC armed：顶栏 `REC·TRK 05` 闪，选中轨 bar 边变红（REC 语义总表 = 02 §5）
