# DriftSeq 屏幕设计 (03)

**日期**: 2026-10-14 · **状态**: draft → review
**前置**: 00（"看见漂移"支柱）、02（面板：14 按钮 2×6+OCT、7 encoder、27 键 F3–G5）
**屏幕**: 240×240 彩屏，字库走 melodee 的 ter-u16（16px）/ ter-u12 路线。设计原则照 melodee：
**底部 4 个大字框 = KNOB1–4 当前参数的实时代显**（melodee 的 TUNE/TONE/DECAY/SNAP 4 框即此语法），
屏幕永远能回答"我现在拧的这颗 K 在改什么"。

## 0. 全局帧布局（所有页面共用）

```
┌──────────────────────────────────────────────────┐ y=0
│  TRK 03 │ PTN 05 │ 119 │ U/G/B │ GRID           │  顶栏 16px：
├──────────────────────────────────────────────────┤ y=16
│                                                  │
│                                                  │  主区 200px：
│                                                  │  页面内容（见下）
│                                                  │
├──────────────────────────────────────────────────┤ y=216
│  LOOP LEN 64 │ DIV 1/16 │ ROUTE GM │ CH 010      │  底栏 24px：
│  (K1)        │ (K2)     │ (K3)     │ (K4)       │  K1–K4 大字框 ×4
└──────────────────────────────────────────────────┘ y=240
```

- 顶栏：选中轨号 / pattern 号 / BPM / route 字形（U=USB G=GM B=Both）/ 当前模式（GRID/PLAY）
- 底栏 4 框：固定对应 K1–K4，**显示的是"当前上下文下"这 4 颗 K 绑定的参数**（随页面/选中步切换）——
  这是"手不用看旋钮就知道在改什么"的核心
- 高亮色：选中轨/选中步用 accent（melodee 的 ACCENT 色），其余灰阶

## 1. HOME 总览（GRID 模式主屏）——**"漂移可视化"hero 屏**

16 条横向 loop bar 叠满主区（16×12px=192 + 8px 间隙）：

```
 TRK  LOOP LEN  ┌──────────────────────────────┐
 01   64  U     │██▓▓▓▓▓▒░░░░░░░░░░░░░░░░░░░░░░│▌← 16 步鼓，playhead 慢
 02   12  B     │▌███░░░░░░░░░░░░░░░░░░░░░░░░░░│← 12 步 bass，playhead 快
 03   48  G     │░░░░░▌████████████████░░░░░░░░│← 48 步 pad
 04   16  U     │░░░░░░░░░░░░░▌░░░░░░░░░░░░░░░░│
 ...
 16   32  G     │░░░░░░░░░░░░░░░░░░░░░░░░░▌░░░░░│
```

- 每行一条 bar 代表**该轨自己 loop 的一整圈**（bar 宽度 = 该轨 loop_len 的归一化，不等长 → 不同填充速率）
- `▌` = playhead；**不同轨的 playhead 逐渐错位 = 相位漂移，直接看见**（支柱 2 的落地）
- 左端：轨号(2位) + loop_len(2位) + route 字形（**A**=all **B**=ble **U**=usb）；行可点选（SELECT 循环 / 黑键区点击）
- 选中行高亮；mute 的轨变暗 + 加 `M`
- **这屏不画 step 细节**，只画 16 条相位——它是"全局状态"，不是"编辑工具"
- 顶栏不放模式字（GRID/PLAY），屏内容本身自明；顶栏 = `TRK nn │ PTN nn │ BPM`，右侧角标 = 选中轨
  loop_start 读出 `S nn`（绿色）——K3 拧动时亮带在动，角标给数字锚点（"确切位置"）
- **纵向预算恰满**：20px 顶栏 + 16×12px 行 + 20px 底栏 = 240px；HOME 不设额外读出行
  （曾试过 S/L 独立行，16 号轨被挤出屏，废）——LEN 已在每行行首，不重复显示选中轨 LEN

### 1.1 HOME 页底栏 K1–K4（每屏绑定不同；此页 = 选中轨的漂移/演奏参数）

| 框 | 参数 | 动作 |
|---|---|---|
| K1 | `LOOP START` | 拧动即时改选中轨 loop_start（亮带整体平移，hero 屏直接可见；顶栏 S 角标实时跳） |
| K2 | `LOOP LEN` | 拧动即时改选中轨 loop_len（live morph：窗口收缩越过的已触发音 gate 走完不硬切；行首 LEN 实时反映） |
| K3 | `MUTE` | 拧动切换选中轨 mute（行首加 `M`、bar 变暗、顶栏 S 角标变暗） |
| K4 | `PROB` | 选中轨 cursor 步的 prob（±5%/格） |

- SELECT 换轨 → 4 框立即跟随新选中轨的值；PLAY 中拧 K1/K2 = "现场拖亮带"（00 §支柱2）
- **SELECT 不循环**：拧到 16 即停（未来加加速——快拧直接跳 TRK01/TRK16，便于盲操；
  先按物理行程自然端点实现）
- 这 4 框是 HOME 页的**唯一** K 语义；SEQ/EDIT/ARP/GLO/PLAY 各页另有绑定（§7 总表逐页列出）
- emu 已按本表实现；§7 旧表 HOME 行"len/div/route/ch"作废、已同步为本表

### 2.1 OCT± = 键床翻页，屏保持全览

- **为什么翻页**：键床只有 16 白键（硬件约束），一次只能"摸"16 步；OCT−/OCT+ 换的是
  **手指落在哪一页**（白键 LED 长亮 = 该页 step on，闪 = playhead，02 §2.1 语法）
- **屏不跟随裁剪**：240×240 放得下 64 步全览，裁成 16 格反而丢全局。屏上**当前页行全亮、
  其余行压暗**——OCT± 按下时看见亮行移动，键、屏、页三方永远对齐
- 每行行首画 `P1..P4` 页号小字

### 2.2 单格语义（~14×45px，melodic 轨；drum 轨走 §2.3 专用视图，不适用本节）

```
┌──────┐   on 格填充色 = v0 音高的**色相**（12 半音 × 30° 色环，钢琴卷帘惯例）
│▓▓▓▓▓▓│   窗口外 on → 灰化（存在可见，不在 loop 内）
│▓▓▓▓▓▓│   playhead 步 → 白描边；cursor 步 → 黄描边
│▓▓▓▓▓▓│   v1..3 → 格底 3px 色条，各自音高的色相（poly 一眼可见几个音）
├──────┤
│▁▁▁▁▁▁│
└──────┘
```

> 鼓轨单格不走本节：ch10 轨整屏切 §2.3 lanes 视图（lane 内单格 = 该鼓 on/off，乐器色），
> 色相=音高的语义对鼓无意义——鼓色定义收编在 §2.3。

- **已知局限（John 拍板：留待 real-time record 一并解决）**：色相只承载 pitch 单维——
  **和弦**（>2 voice 时色条挤在 3px 槽里）与**时值/gate**（格内无长度信息）都表现不了。
  未来方案候选：gate → 格内右向延长条；和弦 → EDIT 页细编承载，网格保持单维可读性
- **精确音名**不给格子塞字（14px 塞不下也不可读）：选中/cursor 步的音名上**顶栏角标**
  （`st18 C3`，与 HOME `S nn` 同语法），完整细节在 EDIT 页（§3）
- prob<100 的 on 格：底部已有暗条（v1 emu 语法保留）

### 2.5 步"选中"手势——cursor 移动方式 **melodic 与 drum 分开**（→ EDIT 的对象来源，§3.1）

无独立选中态，**cursor 即选中**（黄框）——cursor 是常驻单值（0..63，初始 0），任何时刻都指向
明确的步，**"选中"这件事两轨型语义一致**；分开的只是 cursor 的**移动手段**：

**melodic 轨**（键床 = 纯音高键；cursor 移动全在旋钮——rev.5 John：白键点选跳格作废，
STEP-ENTRY 无进出、是常态）：

| 手势 | 动作 |
|---|---|
| **K1 左旋 / 右旋** | cursor 后退 / 前进一格——**纯 cursor 轴**，主移动手段 |
| **GLO 长按+K1** | 快速移动：每拧 1 格跳 16 步（一页）——跨页定位比 OCT 连按快 |
| 弹键（白/黑键） | 写入 cursor 步一个 voice + 试听；和弦 ≤4，全松开自动前进一格 |
| **OCT−/OCT+** | **键床音程移位 ±12**（rev.7 John 纠错：弹键音域只有 F3–G5，OCT± 必须留给移位，否则高低音写不进；顶栏角标显示 `+12`，松开归零，可叠到 ±24） |
| EDIT 页 OCT−/OCT+ | cursor 后退/前进一格（EDIT 内键床不弹奏，无移位冲突） |
| rest/tie 三态循环 | 迁至 EDIT 页 GLO 长按+K4（rev.7：GRID 内 rest 少用，同音重弹即清除；tie 的输入口在 EDIT） |

> rev.5 记录：白键点选跳格曾是 melodic 的选择手段，其卖点"盲操"在步录入常态下无意义
> （弹键写步本来就在 step-entry 语义里，眼睛早就在屏上了）——作废，cursor 移动全归 K1。
> 白键点选若将来复活，只在"屏上点格"不可用的场合（无触屏真机 + 屏幕坏了）作为恢复路径。
**drum 轨**（键床 = 鼓机面板：黑键选鼓、白键 toggle 该鼓发音位）：

| 手势 | 动作 |
|---|---|
| 黑键 | **选鼓**（drumSel；白键 toggle 的对象跟着变）——不移动 cursor |
| 白键 | toggle 当前选鼓在该格的 on/off——**编辑动作，不是选择** |
| **屏上点 lane 格**（emu/真机触屏） | cursor 跳到该格（触屏是鼓轨唯一"跳步"手势） |
| EDIT 页 OCT−/OCT+ | cursor 后退/前进一格（同 melodic） |
| EDIT 页内白键 | 试听当前选鼓（不入 voice——写入只发生在 GRID toggle） |

- 分开的理由：melodic 键床 = **纯音高**（移动/写入由旋钮+弹键分工，钢琴心智），drum 键床 =
  **乐器选择+开关**（808 心智）——两套肌肉记忆都成立，但**不互换**；cursor 在 drum 轨退居
  "EDIT 细编的定位器"，GRID 日常编辑（铺/删鼓点）完全绕开它
- EDIT 页对 drum 轨显示同一张 voice 卡片列表（该步全部鼓音各一行），K1 COND/K4 PROB 同语义；
  K2 GATE/K3 VEL 作用于活动 voice（= 屏上高亮的那行鼓音）

## 3. EDIT 步细编（EDIT 键进入；对象 = 选中步 = SEQ 页黄框格 / STEP-ENTRY cursor 格）

进入即锁定"选中步"；无选中步时显示 cursor 步。主区 = 该步的 **voice 卡片列表**（≤4）：

```
┌──────────────────────────────────────────────────┐
│ EDIT TRK 05 · st18 A3                    (选中步) │ 顶栏16px（角标=v0 音名）
├──────────────────────────────────────────────────┤ y=16
│  v1  ▶ A3  057    VEL 100  GATE 1.00  [PLAY中]  │  每 voice 一张卡：
│  v2  ● C4  060    VEL 084  GATE 0.50            │  note 名+号 / vel / gate
│  v3  ○ E4  064    VEL 090  GATE 2.00            │  ▶=发声中 ●=静默保留 ○=off
│  v4  ─ 空                                        │  空卡 = 黑键弹入新音
├──────────────────────────────────────────────────┤ y=216
│ PITCH A3    │ GATE 1.00  │ VEL 100   │ PROB 100% │ 底栏24px（作用于活动 voice）
│ (K1)        │ (K2)       │ (K3)      │ (K4)      │ cond=GLO 长按+K1
└──────────────────────────────────────────────────┘ y=240
```

### 3.1 进入/离开与选中步的来源

- **EDIT 键 toggle**：SEQ/任意页 → EDIT；再按回 SEQ。屏身份自明（无模式字）
- **EDIT 永远有对象**：cursor 常驻单值（初始 0，永不空），进入 EDIT 即编辑 cursor 所指步——
  无需先"选中"（John：既然始终有 cursor，cursor 位置就算选中）。melodic/drum 的差别只在
  **cursor 怎么移动**（§2.5 两张表），选中语义本身两轨型一致
- **"选中" = cursor（John 定：始终有 cursor，cursor 位置即选中）**：无独立选中态——cursor
  是常驻单值（0..63，初始 0），任何时刻 EDIT 都有明确对象，**不存在"未选中"空态**；SEQ 与
  EDIT 共享同一 cursor（一个状态两个视图）。melodic/drum 的差别只在**cursor 怎么移动**，
  不在选中语义本身（详见 §2.5 两张表）：
  - melodic：**K1 = cursor 轴**（GLO 长按+K1 = ×16 快进）——白键只当音高键，不参与选择；
  - drum：屏上点 lane 格 = cursor 跳格（白键是编辑不是选择），黑键选鼓不动 cursor；
  - **OCT± 语义收口**（rev.7）：GRID 步录入 = **键床音程移位 ±12**（弹键音域 F3–G5 的硬约束）；
    PLAY = octave shift；EDIT 页 = cursor 前进/后退一格；键床翻页降级为 GLO 长按+OCT±
- **黑键弹入 = 给该步加 voice**（melodic；同 STEP-ENTRY 语义：立即试听、同音再弹 = 移除）——
  drum 轨的写入只发生在 GRID toggle（§2.5），EDIT 页白键 = 试听当前选鼓
- 白键（melodic，EDIT 页）= 试听 v0（不出写入手势，防止误触破坏）

### 3.2 四张 voice 卡与两颗旋钮的分工（SELECT 定对象，K1–K4 改参数）

- **SELECT 拧 = 切活动 voice**（v1↔v2↔v3↔v4 循环，活动卡反白）——SELECT 在 GRID 管轨、
  在 EDIT 管 voice，都是"选对象"职责；EDIT 页**不占 SELECT**（轨选择退场：已进细编，改轨
  按 SEQ 回去）
- **K1–K4 作用于活动 voice**（PROB 例外 = 步级）：
  - **K1 = PITCH**：活动 voice 音高 ±半音（不循环节制 0..127 端点死停）；比"退回 GRID 重弹"
    快，microtonal 微调也走这里
  - **K2 = GATE**：×0.25 步（0.25..8.00，∞ 见 §3.4）
  - **K3 = VEL**：1..127
  - **K4 = PROB**：0..100% 步级（prob 属 step 不属 voice，01 §2）
- **GLO 长按+K4 = rest/tie 三态循环**（rev.7 自 GRID OCT+ 迁入）：按 1 下 = rest（en=0 静默
  保留， voices 不删）、2 下 = tie（gate=0xFF 延音线，01 §2 引擎既有值的唯一输入口）、
  3 下 = 复原；**microstep（开始点偏移，John 提）排在其后**：v1 引擎无此字段——v1.1 候选
  （`ds_note` 加 `offset` u8，humanize/flam 用），落引擎前屏显占位 `MS ±0`，届时 GLO+K4
  变四态循环（rest→tie→microstep→复原）
- **删除 voice**：活动卡上**同音重弹**（STEP-ENTRY 同语义"同音重按 = 移除"）——无需删除键
- 屏上第 4 卡永远显示 v4 或"空"——空卡提示"弹黑键可加"；黑键弹入 = 加 voice 并立即成为
  活动 voice（接着拧 K2/K3 直接细调它）

- GATE 单位 = 本轨 division 步（`gate in steps of this track's division`，01 §2）——
  屏显换算好的小数，拧 1 格 = +0.25 步；`0xFF=until next event` 显示为 `∞`（live morph 时可用）
- cond 与 PROB 的判定顺序见 01 §4（cond 不过 = 整步静默；prob 在 cond 通过后独立掷骰）

### 3.4 cond 大字区（GLO 长按+K1 拧动时的反馈）

- **cond 从底栏 K1 让位给 PITCH**（rev.6）：cond 走 **GLO 长按+K1**（步级枚举不常用，
  修饰层正合适）；拧动时右侧 1/3 屏放大显示 11 态名 + 序号（`4/11 EVERY3`），停止 1s 缩回
  常显——唯一需要"放大反馈"的枚举参数

## 4. ARP / Euclid 页

- 主区：选中轨的 **Euclid 图形**——n 个点里 k 个亮（旋转 rot），一屏看节奏型
- 底栏 4 框：`K`(K1) `N`(K2) `ROT`(K3) `重铺↔脱离`(K4 拧动 toggle)
- 非 Euclid 轨：显示"该轨未用 Euclid，重铺将生成"

## 5. GLO 全局页

- 主区：**route 矩阵**——16 行 × 3 列（U/G/B），选中列高亮 = 每轨 route 一览；
  或 BPM/swing 大字模式（SELECT 切）
- 底栏 4 框：`BPM`(K1) `SWING`(K2) `MASTER VOL`(K3) `CLOCK`(K4: int/ext)

## 6. PLAY 模式

- 顶栏同，模式=`PLAY`
- 主区：**选中轨的单条大 loop bar**（放大版 hero，只 1 轨，含 step 刻度）+ 上方当前弹奏的
  note 名滚动；OCT± 此时 = octave shift
- 底栏 4 框（演奏绑定，02 §4）：`CC1`(K1) `CC2`(K2) `CC3`(K3) `CC4`(K4)
- REC armed：顶栏 `REC·TRK 05` 闪，选中轨 bar 边变红
