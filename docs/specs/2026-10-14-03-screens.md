# DriftSeq 屏幕设计 (03)

**日期**: 2026-10-14 · **状态**: draft → review
**前置**: 00（"看见漂移"支柱）、02（面板：14 按钮 2×6+OCT、7 encoder、27 键 F3–G5）
**屏幕**: 240×240 彩屏，字库走 melodee 的 ter-u16（16px）/ ter-u12 路线。设计原则照 melodee：
**底部 4 个大字框 = KNOB1–4 当前参数的实时代显**（melodee 的 TUNE/TONE/DECAY/SNAP 4 框即此语法），
屏幕永远能回答"我现在拧的这颗 K 在改什么"。

## 0. 全局帧布局（所有页面共用）

```
┌──────────────────────────────────────────────────┐ y=0
│  TRK 03 │ PTN 05 │ 119 │ U/G/B │ GRID           │  顶栏 16px：
├──────────────────────────────────────────────────┤ y=16
│                                                  │
│                                                  │  主区 200px：
│                                                  │  页面内容（见下）
│                                                  │
├──────────────────────────────────────────────────┤ y=216
│  LOOP LEN 64 │ DIV 1/16 │ ROUTE GM │ CH 010      │  底栏 24px：
│  (K1)        │ (K2)     │ (K3)     │ (K4)       │  K1–K4 大字框 ×4
└──────────────────────────────────────────────────┘ y=240
```

- 顶栏：选中轨号 / pattern 号 / BPM / route 字形（U=USB G=GM B=Both）/ 当前模式（GRID/PLAY）
- 底栏 4 框：固定对应 K1–K4，**显示的是"当前上下文下"这 4 颗 K 绑定的参数**（随页面/选中步切换）——
  这是"手不用看旋钮就知道在改什么"的核心
- 高亮色：选中轨/选中步用 accent（melodee 的 ACCENT 色），其余灰阶

## 1. HOME 总览（GRID 模式主屏）——**"漂移可视化"hero 屏**

16 条横向 loop bar 叠满主区（16×12px=192 + 8px 间隙）：

```
 TRK  LOOP LEN  ┌──────────────────────────────┐
 01   64  U     │██▓▓▓▓▓▒░░░░░░░░░░░░░░░░░░░░░░│▌← 16 步鼓，playhead 慢
 02   12  B     │▌███░░░░░░░░░░░░░░░░░░░░░░░░░░│← 12 步 bass，playhead 快
 03   48  G     │░░░░░▌████████████████░░░░░░░░│← 48 步 pad
 04   16  U     │░░░░░░░░░░░░░▌░░░░░░░░░░░░░░░░│
 ...
 16   32  G     │░░░░░░░░░░░░░░░░░░░░░░░░░▌░░░░░│
```

- 每行一条 bar 代表**该轨自己 loop 的一整圈**（bar 宽度 = 该轨 loop_len 的归一化，不等长 → 不同填充速率）
- `▌` = playhead；**不同轨的 playhead 逐渐错位 = 相位漂移，直接看见**（支柱 2 的落地）
- 左端：轨号(2位) + loop_len(2位) + route 字形；行可点选（SELECT 循环 / 黑键区点击）
- 选中行高亮；mute 的轨变暗 + 加 `M`
- **这屏不画 step 细节**，只画 16 条相位——它是"全局状态"，不是"编辑工具"

## 2. SEQ 网格（选中轨编辑）

- 主区：**16 白键步网格**（横排 16 格 = 本页 16 步；OCT± 翻 4 页到 64 步）
  - 格 LED 语义映射到屏：on=实心、off=空心、playhead=顶边 accent 条、**选中步=反白框**
  - 选中步时屏上网格上方画 picker 音域条（当前音域 F3–G5 + OCT 位移，已写入 voice 的音高点亮，
    弹奏时实时跟随）——替代旧"11 槽 pitch 带"（选中制下无固定槽）
- 底栏 4 框（步未选）：`LOOP LEN`(K1) `DIVISION`(K2) `ROUTE`(K3) `CHANNEL`(K4)
- 选中步后底栏 4 框切到：`PITCH`(K1) `GATE`(K2) `VEL`(K3) `PROB`(K4)；cond 走 ARP/EDIT 页
- SHIFT+两点设 loop 窗口：屏上窗口外 dim，**窗口起点画实竖标、窗口本体画亮带**（hero 屏同步：
  每轨 bar 从该轨 loop_start 起亮——起点不一致本身是漂移的一部分）
- **live 窗口变形**（PLAY: K3=START K4=LEN；GRID: K1=LEN K3=START，见 02 §2.1）：改动即时生效，
  底栏对应框大字跟显；窗口收缩越过的已触发音不硬切（gate 走完）——hero 屏上就是"现场拖动亮带"，
  漂移形态实时重塑的可见反馈

## 3. EDIT 步细编

- 主区：选中 step 的**大字 pitch 值**（如 `A3 57`）+ 多 voice 列表（≤4 音各一行 note+vel）
- 底栏 4 框：`COND`(K1) `GATE`(K2) `VEL`(K3) `PROB`(K4)
- cond 值大字在右：`每2圈 / 仅首圈 / 末4圈 / FILL / flam / —`（01 §4 枚举的文字名）

## 4. ARP / Euclid 页

- 主区：选中轨的 **Euclid 图形**——n 个点里 k 个亮（旋转 rot），一屏看节奏型
- 底栏 4 框：`K`(K1) `N`(K2) `ROT`(K3) `重铺↔脱离`(K4 push toggle)
- 非 Euclid 轨：显示"该轨未用 Euclid，重铺将生成"

## 5. GLO 全局页

- 主区：**route 矩阵**——16 行 × 3 列（U/G/B），选中列高亮 = 每轨 route 一览；
  或 BPM/swing 大字模式（SELECT 切）
- 底栏 4 框：`BPM`(K1) `SWING`(K2) `MASTER VOL`(K3) `CLOCK`(K4: int/ext)

## 6. PLAY 模式

- 顶栏同，模式=`PLAY`
- 主区：**选中轨的单条大 loop bar**（放大版 hero，只 1 轨，含 step 刻度）+ 上方当前弹奏的
  note 名滚动；OCT± 此时 = octave shift
- 底栏 4 框（演奏绑定，02 §4）：`CC1`(K1) `CC2`(K2) `CC3`(K3) `CC4`(K4)
- REC armed：顶栏 `REC·TRK 05` 闪，选中轨 bar 边变红

## 7. 页面路由（按钮 → 页，对应 02 §5）

| 页 | 进入键 | 底栏 K1–K4 绑定 |
|---|---|---|
| HOME 总览 | HOME | 选中轨的 loop len/div/route/ch |
| SEQ 网格 | SEQ | 轨级 或 步级（见 §2） |
| EDIT 细编 | EDIT | cond/gate/vel/prob |
| ARP Euclid | ARP | k/n/rot/重铺 |
| GLO 全局 | GLO | bpm/swing/vol/clock |
| PLAY 演奏 | HOME(切换模式) | CC1–4 |

SEL 键 = 把选中轨参数拉进当前页底栏（02 §5）；不切页。

## 8. 待 John 拍板
