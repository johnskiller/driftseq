# DriftSeq — FM-1 上的 master MIDI sequencer

**日期**: 2026-10-14 · **状态**: draft → review
**来源**: idea 3 thread (1559803298507137116) 讨论蒸馏 · 相关 repo: `fm1-ctrl`（骨架层代码复用源）

## 定位

FM-1 上的 **16 轨复音 master MIDI sequencer**：pattern 乐器，不是 workstation/编曲机。

- 占位：**SQ-64 的工作流 + QY100 的 16 复音轨 + 自带 GM 监听**，长在同一台 240×240 机器上
- 不是 workstation（那个座位属于 QY100/Polly）：无 song/section 线性编排，pattern chain 就是全部的"曲式"
- 不是 SQ-64 复刻：SQ-64 = 3 单音旋律轨 + 1 鼓轨、无复音、OLED 单行；DriftSeq = 16 复音轨 + 大屏同看所有相位
- 与 Polly 不冲突：Polly 是 style 驱动的 auto-accompaniment（QY70 系），DriftSeq 是手画 + 生成式的 pattern 乐器（Elektron/SQ-64 系）

## 设计支柱（按优先级）

1. **Per-track loop**：16 条轨各自独立 loop 长度，同时转，相位漂移是产品核心
2. **看得见**：240×240 同屏显示所有轨的 loop 相位错开——漂移是看见的，不是猜的
3. **生成式变换**：Euclid / per-step probability / conditions（对比 SQ-64：PROB+ALTERN 已是市场标配，条件库要更宽，如 last-4-bars）
4. **Master rig brain**：每轨独立 USB MIDI out（channel 可配），接 MPC/桌面 rig
5. **GM 监听**：内置 Sonivox EAS（212 KB bank，抄 Polly 配方），EAS parser 吃与 USB OUT 同一股字节流（loopback）——草稿出声 ≡ MPC 出声；附赠 MIDI-in→GM module 模式
6. **三层输入**：实时录（量化/overdub/note repeat/和弦捕获）+ grid step（鼓 lane 2×16 矩阵）+ GRID/PLAY 键位双身份

## 非目标 (not v1)

song/section 编排（只有 chain）、板载音色设计（GM 之外无引擎）、audio 录入、CV/DIN 硬件输出。

## 与 fm1-ctrl 的关系

**独立 repo，代码级复用而非包含**：keyscan / encoders / leds / midi_io 模块在 fm1-ctrl
先经 host 测试跑通，DriftSeq 建仓时拷贝（GPL-3.0，生态惯例）。两 repo 同 License。

## 工作量（增量估）

- 引擎 + UI 底座（无 GM）：~2 周（Polly 流水线：spec → host sim → emu → FW）
- GM 监听增量：+2–3 天（vendor EAS 0.5d / audio sink 0.5d / loopback router 0.5d / UI 1d）+ 1 天上机
- 实时录 + note repeat：+1.5–2 天
