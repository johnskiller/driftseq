# DriftSeq 输入设计 (02)

**日期**: 2026-10-14 · **状态**: draft → review (rev.2: 真实面板校准)
**前置**: 00-master（三层输入共识）、01-core-model（track/step/condition 模型）
**面板事实源**: melodee HAL `panel.c`（硬件校准表）——**14 按钮**（FX SCL ENV LFO EDIT GLO HOME SAVE ARP
SEQ PLAY REC OCT− OCT+）、**7 encoder**（SELECT ALGORITHM PRESETS KNOB1–4）、**27 键 = F3–G5**
（16 白键 + 11 黑键，键 id 0..26 = F3..G5）

## 1. 模式骨架

全局两态：**GRID**（编辑）与 **PLAY**（演奏），REC 是叠加态（armed）。

- 切换：HOME 长按 0.5s 在两态间翻转（HOME LED 常亮 = GRID，熄 = PLAY——transport 状态本来就由
  PLAY/REC 键自己的 LED 表达，HOME 空闲）
- 状态机核心不变量：**键的语义由"按下时刻的模式"决定**，切换瞬间释放全部 held 键的语义
  （防跨模式粘连）

## 2. 27 键双身份（F3–G5：16 白 + 11 黑）

### 2.1 GRID 模式（步进网格）

- **16 白键 = 16 步/页**：LED 长亮 = step on，闪 = playhead（Felucca GRID 已验证语法）；64 步轨 =
  4 页（OCT± 键床翻页保留，但**定位主手段 = GLO 长按+K1**——拧一格跳 16 步）
- **单击 = toggle**（纯鼓机手感：灭→亮并试听一声、亮→灭；**off = 静默保留**（01 §2 的 en 位）——
  voices/参数永不因单击丢失，再单击复活）。铺骨架、删格都是单击，没有双击
- **鼓轨 GRID 编辑（ch10）**：黑键 = **选鼓**（黑键序 → GM 鼓音表，按住即试听；被选鼓的黑键 LED 点亮），
  白键 = toggle 该鼓在 16 步的开关——经典 TR-808 手感（16 buttons × 1 instrument）
  - **屏 = 全鼓 lanes（所有鼓同时显示）**（John 拍板：对齐鼓点需要看相对位置——其他 FW 惯例）：
    240×240 主区画 ~9 lanes × 64 步（lane = GM 鼓音、顺序 = 黑键序），当前选鼓 lane 高亮、
    其余压暗；lane 左端 3 字符乐器缩写（KCK/SNR/CHH/OHH/CUP…）
  - 键/屏同步：白键 LED = **当前选鼓**在本页的发音位（一颗键只亮一种鼓的状态——多鼓同时可见
    靠屏，不靠键），闪 = playhead
  - 黑键 11 颗 > 常用鼓音 9：末 2 黑键预留（v1.1 percussion/拍手扩展），选不满不报错
- **步录入 = 常态，无进出**（rev.5，John：消除"STEP-ENTRY 模式进出"的困惑——GRID 主页永远处于
  step-entry 语义：cursor 常驻单值、弹键即写、K1 即移动。~~ENV+LFO 同按进出~~作废；实时录音 =
  REC 键 arm，与步录入并行不悖）：
  - 屏上 cursor 反白在当前格；**弹键 = 写入 cursor 步一个 voice 并试听**（同时按多键 = 和弦 ≤4，
    全部松开后 cursor 自动前进一格——QY 行为）
  - **K1 = 纯 cursor 轴**（rev.3 起：只管移动，左旋后退一格 / 右旋前进一格，**不写任何东西**。
    rev.5：~~白键点选跳格~~作废——cursor 轴在手上，白键专心当音高键，消掉键床的双身份；
    **GLO 长按+K1 = 快速移动**，每拧 1 格跳 16 步（一页），跨页定位比 OCT 连按 4 次快）
  - **OCT+ = rest/tie 三态循环**（rev.4，John：单键三态——按第 1 下 = **rest**（当前步 en=0，
    voices 数据保留、GRID 单击可复活），第 2 下 = **tie**（gate = 0xFF until-next-event，即延音线
    接到下一个有音的步——01 §2 引擎已有此值，正好给它一个输入口），第 3 下 = **恢复原状**
    （清除 rest/tie 标记，回到进入时的样子）——**不前进**，看屏确认了再 K1 右旋走人；
    "清除刚才弹的" = K1 左退 → OCT+ 一下（rest）；"连音" = 弹音 → OCT+ 两下（tie）
  - **K2–4 = cursor 步参数**：GATE/VEL/PROB（pitch 由弹的键决定；cond 走 EDIT 页）；
    同音重按 = 移除该 voice；第 5 voice 拒绝（LED 闪）
  - 回改工作流小结：**不满 → K1 左退 → 重弹（新音加 voice / 同音重按删旧）**；
    **清除 → K1 左退 → OCT+（en=0 静默，可复活）**；跳过空步 → K1 右旋（空格无标记）
  - 鼓轨同法：弹键 = 换 cursor 步的 GM 鼓音
- **黑键**：键床音域内 = 键盘黑键（升降号，弹键写入含黑键音）；**GLO 长按+黑键 = 多功能排**，
  按出厂丝印取义（John 实物：`OP1–OP6 · PIT · GLO · MONO · POLY`）：`MONO/POLY` = 选中轨 voice mode（01 §2）、
  `GLO` 黑键 = 跳全局页、`PIT`+OCT± = 全轨 transpose、`OP1–6` 保留（候选 LFO/ENV 深度，v1.1）；
  **GLO 长按 + 黑键 = 第二层修饰排**（John：GLO 长按本来就可以配合黑键丝印）——
  `PIT`+OCT± 即挂此层（= GLO 长按+PIT+OCT±），`OP1–6` v1.1 候选同挂（如 per-track groove 深度、
  LFO 深度等"深度/微调"类参数——丝印本义）；键位就在黑键排上，单手可及
- **loop 窗口 = GLO 长按+单击两点**（第一点 = loop_start、第二点定 loop_len = 从 start 到该步的距离——
  替代旧"拖选"，避免与单击 toggle 冲突；对应 01 §2 的 `loop_start`+`loop_len`，SQ-64 RANGE 语义）。
  修饰键 = **GLO 长按**（§6-7：面板无 SHIFT 键，GLO 长按兼任；Home 长按已被模式切换占用）
- **live 窗口变形（John：play 途中用旋钮动态 change start/len 会很酷）**：PLAY 模式下 K3=START、
  K4=LEN（改动即时生效，全 notes-safe——len 收缩时窗口外已响音走完各自 gate，不发 note-off 断奏）。
  语义即 RESYNC-free 的实时 polymetric 变形：drum 不动、bass 窗口滑动/伸缩，漂移形态现场重塑。
  GRID 的 K1 改 len、K3 改 start 同规则。engine 侧 = 纯参数读（tick 时取当前值），无特殊路径——
  天然确定性，golden hash 直接覆盖"拧到一半"的场景

### 2.2 PLAY 模式

- **原生钢琴弹奏**：白键 = 自然音（F3–G5，两个半八度出头），黑键 = 升降号——不重映射，FM-1 本来身份；
  OCT−/OCT+ = octave shift（本职责）
- 可选 scale 模式（**GLO 长按+SEL** 开关——丝印 SEL，生态惯例当 scale 键用、代码多写 SCL，muscle memory
  保留在修饰键组合里；白键归音阶、黑键=和弦，CTL-1 验证过的交互，v1.1）
- 按键直接出声（GM 或 USB，看当前选中轨 route），REC armed 时写入选中轨

## 3. 实时录音（REC 态）

| 手势 | 行为 |
|---|---|
| 按住 REC + PLAY | arm 选中轨，从下一 loop 边界开录 |
| 弹键盘 | 量化写入（粒度 = 轨 division；quantize 关 = **GLO 长按+REC**） |
| loop 转回 | overdub 叠录；长按 REC 0.5s = erase 模式（松手停，见 §6-3） |
| 按住某键 | note repeat：按拍值 retrigger（1/4→1/8→1/8T→1/16 循环，**GLO 长按+K4** 选拍值，§6-2） |
| 和弦捕获 | 同一 quantize 槽内多键 = 同一 step 多 voice（≤4） |
| 误弹修正 | 按住该键 + 双击对应 step = 只删该音 |

## 4. 7 encoder 分配（SELECT / ALGORITHM / PRESETS / KNOB1–4）

GRID 模式（SELECT 管轨，四颗 KNOB 管轨级或步级，ALGORITHM/PRESETS 管轨级固定项）:

| | SELECT | ALGORITHM | PRESETS | KNOB 1 | KNOB 2 | KNOB 3 | KNOB 4 |
|---|---|---|---|---|---|---|---|
| 步未选中 | 轨选择(16 循环,屏上轨列表跟随) | division | route(USB/GM/BOTH) | loop len | swing amt | MIDI ch | bank/prog |
| 步选中 | 退到步未选(同上) | cond | — | pitch | gate | vel | prob |

- **Euclid**: ARP 键 = Euclid 页（K1=k, K2=n, K3=rot, K4=重铺/脱离 toggle）——三个参数一页屏可见，
  不挤 GRID 主页
- **encoder push 语义（v1 作废——FM-1 旋钮无 push，2026-10-15 John 指正）**：原"按下 =
  翻转该参数常用默认（prob 100↔50、gate 1↔½ 拍)"删除；常用默认翻转改走"快拧"手势
  （见 03 §8 待拍板 #5 的 K1 快拧方案）或后续固件层再议
- PLAY 模式: K1–K4 = 当前轨 CC1–4（bank 由 FX 键换），SELECT = master volume，ALGORITHM = BPM，
  PRESETS = transpose

## 5. 14 按钮分配（真实面板，John 实物确认 2026-10-14）

物理布局（12 键 2×6 两排 + OCT 对键；左列另有 SELECT/ALGORITHM/PRESETS 等 encoder，见 §4）:

```
        ┌─────────────────────────────────────────┐
        │  FX    SEL   ENV   LFO    EDIT   GLO    │   ← 第一排：功能
        │  HOME  SAVE  ARP   SEQ  PLAY/STOP  REC  │   ← 第二排：主控 + transport
        └─────────────────────────────────────────┘
   OCT− / OCT+（独立一对，左列底部）
```

注：SEL 键丝印以实物为准（melodee 的 label 表 best-guess 成 SCL，其校准机制允许按实物重学——以 John 实物 SEL 为准）。PLAY/STOP 是**一颗**键（transport 切换）。

| 按钮 | 位置 | DriftSeq v1 语义 | 长按 |
|---|---|---|---|
| FX | 1-1 | **FILL**（一次性 fill flag，01 §3）——丝印不改，语义重定义 | — |
| SEL | 1-2 | **选中轨参数直显**（把选中轨的 loop len/division/route 拉到大字行，配合 K1–K4 编辑）。丝印 SEL 但生态惯例是 scale 键（melodee 代码写 SCL 即此键）——scale 放 GLO 长按+SEL（v1.1，§2.2） | 轨 mute |
| ENV | 1-3 | v1 备用（LED 熄），候选 per-track groove；**与 LFO 同按 = STEP-ENTRY 进出**（§2.1） | — |
| LFO | 1-4 | v1 备用（LED 熄）；**与 ENV 同按 = STEP-ENTRY 进出**（§2.1） | — |
| EDIT | 1-5 | 步细编页（pitch/gate/vel/prob/cond 大字） | — |
| GLO | 1-6 | 全局页（BPM/swing/route 矩阵） | **SHIFT**（修饰键——§2.1 两点窗口/§3 quantize/§6-2 拍值/v1.1 scale 全挂这里） |
| HOME | 2-1 | **GRID↔PLAY 模式切换**（LED 常亮 = GRID；见 §1） | — |
| SAVE | 2-2 | pattern 快照存 flash | 16 patterns 序列化 |
| ARP | 2-3 | Euclid/生成页（K1=k, K2=n, K3=rot, K4=重铺） | — |
| SEQ | 2-4 | GRID 主页（步进网格） | — |
| PLAY/STOP | 2-5 | transport | — |
| REC | 2-6 | arm 选中轨 | erase 模式（松手停） |
| OCT− / OCT+ | 左列 | GRID 步录入 = **键床音程移位 ±12**（弹键音域只有 F3–G5 两个八度出头，OCT± 必须留给移位——rev.7 John 纠错）；键床翻页降级为 GLO 长按+OCT±；PLAY = octave shift 同语义 | — |

（对比 melodee 的 FAM 语法——HOME 为家族页锚点——DriftSeq 把 HOME 用作模式切换 + 主总览，
其余页键语义平行移植，学习迁移成本最低。）
