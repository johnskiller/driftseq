# DriftSeq 输入设计 (02)

**日期**: 2026-10-14 · **状态**: draft → review
**前置**: 00-master（三层输入共识）、01-core-model（track/step/condition 模型）
**目标**: 键位级手势表——27 键双身份状态机 + 实时录 + 生成操作，落到"每个物理控件在每种模式下做什么"

## 1. 模式骨架

全局两态：**GRID**（编辑）与 **PLAY**（演奏），REC 是 GRID/PLAY 之上的叠加态（armed）。

```
        ┌──────── REC(arm) ────────┐
   GRID │ 27键=步进网格            │ PLAY │ 27键=音符
        │ encoder=轨/步参数        │      │ encoder=实时演奏参数
        └──────────┬───────────────┘      └──────────┬─────────┘
                   └────── HOLD GRID+PLAY 0.5s = 切换 ─┘
```

- 切换：GRID/PLAY 双长按 0.5s（防误触），或 SHIFT+其中之一
- 状态机核心不变量：**键的语义由"按下时刻的模式"决定**，模式切换瞬间释放全部 held 键的语义
  （防跨模式粘连：GRID 里按住的 step 不因切 PLAY 变成音符）

## 2. 27 键双身份

### 2.1 GRID 模式（步进网格）

真实布局：**16 白键 + 11 黑键**（钢琴排布，C3–D5）。

- **16 白键 = 16 步/页**：LED 长亮 = step on，闪 = playhead（Felucca GRID 的已验证语法）；64 步轨 =
  4 页，PAGE 键循环；双击 = toggle on/off；拖选（按住第一个再按第二个）= loop 区间 start/end
- **11 黑键 = pitch/instrument 拾取排**（black-keys-as-pitch-row，idea-1 设计的落位）：
  - 按住某白键 step + 点黑键 = 设置/替换该 step 的音高（旋律轨）或打击乐音色（ch10 轨 =
    instrument 挑选，黑键序 = GM 鼓映射表当前页）
  - 按住 step + **同时按多个黑键** = 多 voice 和弦录入（≤4，同实时录的捕获规则）
- **顶排概念取消**（原先虚构的"上排 5 键"不存在）——轨选择改走 SELECT 键 + enc5（见 §4）

### 2.2 PLAY 模式

- **原生钢琴弹奏**：白键 = 自然音（C3–D5，两个半八度），黑键 = 升降号——不重新映射，直接当 MIDI
  键盘用（这是 FM-1 的本来身份）
- 可选 scale 模式（白键强制归入选定音阶、黑键=和弦，CTL-1 验证过的交互，v1.1）
- 按键直接出声（GM 或 USB，看当前选中轨 route），REC armed 时写入选中轨

## 3. 实时录音（REC 态）

| 手势 | 行为 |
|---|---|
| 按住 REC + PLAY | arm 当前选中轨，从下一 loop 边界开始录 |
| 弹键盘 | 量化写入（量化粒度 = 轨 division；quantize 可关 SHIFT+REC） |
| loop 转回 | overdub 叠录（不清旧），长按 REC 0.5s = 换 erase 模式（松手停） |
| 按住某键 | note repeat：按拍值自动 retrigger（1/4、1/8、1/8T、1/16 由 NOTE-R 键循环选） |
| 和弦捕获 | 同一 quantize 槽内的多键 = 同一 step 的多 voice（≤4，见 01 §2） |
| 演奏中的错误 | 按住该键 + 按清除键 = 只删该音（不进编辑页） |

## 4. 7 encoder 分配（模式 × 页面）

GRID（编辑选中轨）:

| enc | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| step 未选中 | loop len | division | swing | 轨 route | channel | prog | prob 默认 |
| step 选中 | pitch | gate | vel | prob | cond | eu_k | eu_n |

PLAY（演奏）: enc1–4 = 当前轨的 CC1–4（bank 随 FX 键），enc5 = master volume，enc6 = BPM，enc7 = transpose。

**encoder push**（v1 统一语义）：按下 = 步进翻转该参数默认值（如 prob 100→50），不进菜单。

## 5. 12 按钮分配

| 按钮 | 单击 | 长按 |
|---|---|---|
| PLAY / STOP | transport | — |
| REC | arm 选中轨 | erase 模式 |
| GRID / PLAY | （双长按切模式） | — |
| SELECT | 轨 6–16 循环 | 轨参数页 |
| PAGE | 网格翻页（32→64 步） | pattern 浏览 |
| CHAIN | chain 编辑页 | 拍板 §6-3 热切/cold |
| EUCLID | 对选中轨重铺 | eu 参数页（rot） |
| SHIFT | 组合修饰 | — |
| FILL | 一次性 fill flag（01 §3） | — |
| SAVE | pattern 快照存 flash | 全部 pattern 序列化 |

（12 键里 GRID/PLAY 占两颗；凑不满的用 SHIFT 组合，v1 不加菜单层级。）

## 6. 待 John 拍板

1. GRID 语义 = **16 白键一页 16 步（4 页/64 步）+ 11 黑键 pitch 拾取** vs 白键跨两页合并 32 步长条——
   建议**前者**（语法和 Felucca GRID 一致，学习成本零；pitch 拾取排是净赚）
2. note repeat 的拍值选择：SHIFT+ENC7（省按钮）vs 独立 NOTE-R 键（12 键已满，需挤掉一个）——
   建议 **SHIFT+ENC7**
3. erase 模式交互（长按 REC 进入，松手即停 vs 再按停）——建议**松手即停**（风险低）
4. 轨选择 = SELECT 循环 + enc5 直选 + 屏幕轨列表——还是保留物理直选键（需要占用白键一页做轨页）——
   建议**前者**（白键留给步进，屏幕已有 16 轨全景，enc5 一拧即达）
