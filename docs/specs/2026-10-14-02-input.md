# DriftSeq 输入设计 (02)——操作总原则

**日期**: 2026-10-14 · **状态**: rev.10（并入 03：具体每屏的操作已随屏入 03 各章；本文件只留
跨屏通用的原则、硬件事实与全局语义）
**前置**: 00-master（三层输入共识）、01-core-model（track/step/condition 模型）
**配套**: 03-screens——**每屏长什么样、每屏上怎么操作，以 03 为准**；本文与 03 冲突时以 03 为准
**面板事实源**: melodee HAL `panel.c`（硬件校准表）——**14 按钮**（FX SCL ENV LFO EDIT GLO HOME SAVE ARP
SEQ PLAY REC OCT− OCT+）、**7 encoder**（SELECT ALGORITHM PRESETS KNOB1–4）、**27 键 = F3–G5**
（16 白键 + 11 黑键，键 id 0..26 = F3..G5）

## 1. 硬件不变量（硬约束，一切设计的前提）

- **7 旋钮全部无 push**（2026-10-15 John 实物指正）：参数翻转类操作不能靠"按下"，只能靠
  拧动枚举 / 修饰键组合 / 端点行为设计
- **SELECT 无按住**，面板无 SHIFT 键
- **修饰键 = GLO 长按**（0.5s，§3）：边缘键方便组合、REC 不能占（transport）、FX 留给 punch FX、
  HOME 长按已是 GRID↔PLAY；GLO 短按仍 = 跳全局页
- **GLO 长按+黑键 = 第二层修饰排**：黑键出厂丝印 `OP1–6 · PIT · GLO · MONO · POLY`（John 实物），
  按丝印就近取义——`MONO/POLY` = 选中轨 voice mode（01 §2）、`PIT`+OCT± = 全轨 transpose（挂
  GLO 层）、`OP1–6` 保留（v1.1：LFO/ENV 深度、per-track groove 等"深度/微调"类）
- **27 键 F3–G5，音域只有两个八度出头**（rev.7 硬约束之源）：步录入时 OCT± 必须留给
  键床音程移位，不能挪作他用（03 §2.3）
- 14 按钮物理布局：

```
        ┌─────────────────────────────────────────┐
        │  FX    SEL   ENV   LFO    EDIT   GLO    │   ← 第一排：功能
        │  HOME  SAVE  ARP   SEQ  PLAY/STOP  REC  │   ← 第二排：主控 + transport
        └─────────────────────────────────────────┘
   OCT− / OCT+（独立一对，左列底部）
```

注：SEL 键丝印以实物为准（melodee label 表 best-guess 成 SCL，校准机制可按实物重学）。
PLAY/STOP 是**一颗**键。

## 2. 模式骨架

全局两态：**GRID**（编辑）与 **PLAY**（演奏），REC 是叠加态（armed）。

- 切换：HOME 长按 0.5s 在两态间翻转（HOME LED 常亮 = GRID，熄 = PLAY）
- 状态机核心不变量：**键的语义由"按下时刻的模式"决定**，切换瞬间释放全部 held 键的语义
  （防跨模式粘连）
- GRID 内部页 = 平行视图（03 §7 路由表）：HOME 总览 / MELODY GRID（含 EDIT 面板嵌页）/ DRUM GRID / ARP / GLO；
  **cursor（选中步）与选中轨跨页共享**——换页不换对象

## 3. 修饰层（GLO 长按）

| 组合 | 语义 | 首次定义 |
|---|---|---|
| GLO 长按+K1（GRID） | LOOP START（rev.11：K2=LEN 配对，GRID 页窗口形状全覆盖） | 03 §2.2 |
| GLO 长按+K1（EDIT 层） | cond 枚举 + 大字反馈 | 03 §2.4 |
| GLO 长按+OCT− | 回退一格（步编辑轴，rev.11） | 03 §2.3 |
| GLO 长按+OCT+ | rest/tie/复原 三态循环（rev.11 回迁 GRID；EDIT GLO+K4 同义保留） | 03 §2.3/§2.4 |
| GLO 长按+黑键 | 第二层修饰排（丝印取义） | §1 |
| GLO 长按+SEL | scale 模式开关（v1.1） | 03 §6 |
| GLO 长按+OCT±（PLAY） | octave shift | 03 §6 |
| GLO 长按+REC | quantize off | §5 |
| ~~GLO+单击两点 / GLO+K1 ×16~~ | 作废（rev.11：两点跨页设不了窗口；×16 让位 START） | — |

## 4. 全局交互约定（各页通用）

- **SELECT = "选对象"**：GRID 选轨（不循环，拧到 16 即停；未来加速：快拧跳 TRK01/TRK16）、
  EDIT 选 voice（03 §2.4）——职责单一：永远在换"当前编辑的对象"，从不直接改参数
- **K1–K4 = 当前页绑定参数**（03 各页底栏表即契约；底栏 4 框永远显示当前绑定——
  "手不用看旋钮就知道在改什么"）
- **端点死停不循环**（rev.9，John：盲操优先）：SELECT 到 16 停、cursor 到 st1/st64 停、
  音高 0..127 停——拧过头不丢位置
- **屏显步号 1-based（st1–st64）**（rev.9，John：0 起点是程序员习惯）；内部 0..63 不变
- **SELECT 换轨 → 当前页所有轨级显示立即跟随**（03 §1.1）
- 键的双身份由模式/页面分流，永不并存（各屏表见 03；总原则：GRID 弹键 = 写入、
  PLAY 弹键 = 演奏、EDIT 弹键 = 加删 voice）

## 5. 实时录音（REC 态，叠加于 PLAY/GRID）

| 手势 | 行为 |
|---|---|
| 按住 REC + PLAY | arm 选中轨，从下一 loop 边界开录 |
| 弹键盘 | 量化写入（粒度 = 轨 division；quantize 关 = GLO 长按+REC） |
| loop 转回 | overdub 叠录；长按 REC 0.5s = erase 模式（松手停） |
| 按住某键 | note repeat：按拍值 retrigger（1/4→1/8→1/8T→1/16 循环，GLO 长按+K4 选拍值） |
| 和弦捕获 | 同一 quantize 槽内多键 = 同一 step 多 voice（≤4） |
| 误弹修正 | 按住该键 + 双击对应 step = 只删该音 |
