# DriftSeq 术语表 (05)

**日期**: 2026-10-14 · **状态**: draft → review
**用途**: 锁死产品语言——spec/代码标识符/屏幕文字/UI 一律用这套词，不再各说各话。
（Polly 流水线里 `vocabulary` 那篇的同类产物；放在最后是因为前四篇已把词用尽了，
这里是"追认 + 纠偏"，遇到新词回这里登记。）

## 核心对象

| 词 | 定义 | 代码 | 屏幕 |
|---|---|---|---|
| **track** 轨 | 一条独立循环的声音通道（16 条之一）。有自己的 loop 长度、division、route、channel | `ds_track` | `TRK 03` |
| **loop** 循环长度 | 一条轨重复的步数（1–64）。**per-track**，是 polymetry 的根源 | `loop_len` | `LOOP LEN 64` |
| **step** 步 | loop 内一个时间点，`loop_len` 的 1/N（N=division）。step 可多 voice | `ds_step` | 网格一格 |
| **division** 分频 | 一步的时值：1/8、1/8T、1/16、1/16T、1/32 | `division` | `DIV 1/16` |
| **voice** 音 | 一个 step 内同时响的一个音（≤4/step，和弦=多 voice） | `ds_note` | pitch 排一槽 |
| **pattern** 模式 | 16 条轨（内容+meta）的快照。**pattern ≠ 一段曲子**，是"一套轨状态" | `ds_pattern` | `PTN 05` |
| **chain** 链 | pattern 的有序序列（`{pattern, repeat}`），唯一的"曲式"结构 | `ds_chain` | `CHAIN 05×2→07` |

## 时间 / 相位

| 词 | 定义 |
|---|---|
| **tick** | 引擎从音频回调驱动的时钟脉冲（44100 Hz 渲染粒度） |
| **transport** | 全局 play/stop/BPM 状态；MIDI clock 的 master 源 |
| **BPM** | 全局速度（24 PPQ 发 MIDI clock） |
| **phase** 相位 | 一条轨在它自己的 loop 里当前走到第几步。**相位漂移 = 不同轨的 phase 错开**（产品核心，hero 屏可视化的东西） |
| **swing** 摇摆 | 全局摇摆量 × per-track 比例（01 §6-5） |
| **resync** | 把一条轨的 phase 强制拉回 step 0（对齐 SQ-64 语义） |

## 生成 / 变换

| 词 | 定义 |
|---|---|
| **Euclid** | Bjorklund/Toussaint 欧几里得节奏生成器（`k` 个亮点散在 `n` 个槽，`rot` 旋转）。开=steps 由生成器重铺（01 §4） |
| **probability** 概率 | 每 step 触发概率 0–100%（RNG 种子化，确定性重放） |
| **condition** 条件 | step 的触发条件（每 N 圈 / 仅首圈 / 末 4 圈 / FILL / flam，01 §4 枚举） |
| **step entry** | 选中一步后逐键写入音高的录入法（= 经典 step record 的选中制变体，见 02 §2.1） |
| **fill** 填充 | 一次性触发标志（FX 键置位），条件=FILL 的 step 下一圈生效一次 |
| **flam** 连带 | 前一 step 触发时才触发的条件（01 §4 cond=10） |
| **overdub** 叠录 | 实时录时 loop 转回不清旧、叠新 |

## 路由 / 音源

| 词 | 定义 |
|---|---|
| **route** 路由 | 一条轨的发声去向：`USB` / `GM` / `BOTH`（01 §5） |
| **channel** | 轨的 MIDI channel 1–16（= EAS channel） |
| **bank / program** | GM 音色选择（bank, prog → PC） |
| **GM** | 内置 Sonivox EAS 软音源（手机级，**草稿监听**用，正式出声走 MPC） |
| **loopback** | 引擎字节流同时喂 USB out 和 EAS parser → 草稿 ≡ MPC（04 §3） |
| **MPC** | 用户外接的好音源 rig（DriftSeq 的"正式出声"归宿，产品不内置） |
| **module mode** | MIDI-in 直接进 EAS 的 GM 音源模式（04 §5，白送能力） |

## 交互 / 面板

| 词 | 定义 |
|---|---|
| **GRID** | 编辑模式（27 键 = 步进网格 + pitch 排，OCT± = 步页翻） |
| **PLAY** | 演奏模式（27 键 = 钢琴 F3–G5，OCT± = octave shift） |
| **REC** | 实时录叠加态（arm 选中轨，量化/overdub） |
| **SEL** | 选中轨参数直显键（02 §5） |
| **K1–K4** | 四颗 KNOB encoder，底栏 4 大字框固定绑定（03 §0） |
| **hero 屏** | HOME 总览，16 条 loop bar 显示相位漂移（03 §1，产品 hero） |
| **pitch 排** | GRID 下 11 黑键 = 音高/音色拾取（02 §2.1） |

## 禁用语 / 纠偏（防再犯）

| 别用 | 用这个 | 原因 |
|---|---|---|
| "workstation / 编曲机" | master sequencer / pattern 乐器 | 不是 QY/Polly 那个位（00 定位） |
| "song / section" | chain | v1 无线性编排（00 非目标） |
| "2×14 矩阵" | 16 白键 + 11 黑键（钢琴几何） | FM-1 是真钢琴键，不是均匀 pad（02 教训） |
| "PAGE 键" | OCT−/OCT+（GRID 下 = 步页） | 没有独立 PAGE 键（02 教训） |
| "12 按钮" | 14 按钮（12 键 2×6 + OCT 对） | 实锤 14（02 §5） |
| "SCL" | SEL | 实物丝印是 SEL——但**生态惯例把 SEL 当 scale 键**（melodee 等代码写 SCL 即此键），DriftSeq 的 scale 放 GLO 长按+SEL，纯 SEL 保留给轨参数直显（02 §5） |
| "C3–D5 键域" | F3–G5 | 键 id 0..26 = F3..G5（melodee HAL）（02） |
| 忽略黑键丝印 | 借用 OP1–6/PIT/GLO/MONO/POLY 做多功能 | 黑键出厂多功能字符（John 实物），设计 v1.1 功能时按丝印就近取义（02 §2.1） |
