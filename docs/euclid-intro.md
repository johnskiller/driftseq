# Euclid 是什么 —— 写给鼓机玩家的一页介绍

> DriftSeq 笔记 · 2026-10-16 · 所有图样均由 `host/driftseq.c` 引擎直接输出，非示意。

## 一句话

**把 k 个鼓点尽量均匀地撒进 n 个格子里。** 参数只有两个数：`K`（点数）和 `N`（格子数），外加一个 `ROT`（整体转多少格）。它不生成音色、不生成音高，只回答一个问题：**这一小节里，这一轨在第几格打。**

## 从一个例子开始

`K=3, N=8`，记作 **E(8,3)**——8 个格子里放 3 个点，间隔尽量均匀：

```
x..x..x.        ← "tresillo"，古巴音乐的 three-side
```

"尽量均匀"是关键：3 个点等分 8 格不可能（8/3 不是整数），算法给出的是**最接近等分的唯一解**——间隔 `3,3,2`。人耳听这种"差一点才均匀"的节奏会自动找律动，这正是非洲和拉美音乐几百年里长出来的那些节奏型。事实上，**世界上大量传统节奏都是某个 E(n,k)**：

| 参数 | 图样 | 名字 |
|------|------|------|
| E(16,4) | `x...x...x...x...` | four-on-floor（电子舞曲底鼓） |
| E(8,3) | `x..x..x.` | tresillo（康加舞基础） |
| E(12,5) | `x..x.x..x.x.` | cinquillo 变体（12/8 非洲） |
| E(16,5) | `x..x..x..x..x...` | bossa nova 底鼓 |
| E(16,7) | `x..x.x.x..x.x.x.` | samba 系 |
| E(16,3) | `x....x....x.....` | son clave 的三击侧 |

所以它不只是"数学玩具"——**它是很多真实节奏的公共爹**。你随手拧一个 E(16,5)，就已经在 bossa 上了。

## 引擎怎么算（简版）

每轮把"点桶"和"空桶"两两配对拼接，直到只剩一个空桶，最后连起来。这是 Bjorklund 2005 年给 ISP 芯片写的算法，Toussaint 同年发现它和音乐节奏的关系。我们对齐的是 Toussaint 论文的**规范相位**：第一个点固定落在第 1 格。

三个工程注记（可选读）：

- 网上常见快捷式 `第 i 格 on 当 ⌊i·k/n⌋ 变化` **并不等价**——n=2..64 全组合里它有 1676/2016 个答案不是 maximally even。我们实现的是真算法。
- `k > n/2` 时（点比空多），引擎输出的项链和论文印刷的互为旋转（如 E(4,3) 引擎给 `xxx.`、论文印 `x.xx`）。都合法，`ROT=1` 即得论文朝向。
- `ROT` 的语义是**所有点整体后移 r 格**（循环回绕），白刻 playhead 不动——所以 K3 转起来是"整圈花纹在转"，节拍相位不变。

## 和 DriftSeq 轨道的关系

**每条 track 各有一套独立的 K/N/ROT。** 元数据存在 `ds_track` 上（`eu_on/eu_k/eu_n/eu_rot`），ARP 页里 SELECT 换轨，K1–K4 只动当前轨；没有"一键铺多轨"。

- **鼓轨**：这是它的主场。Kick/Snare/Hat 各占一轨，各配各的 E(n,k)——demo 里就是 E(16,4) kick + E(12,5) + E(8,3) 的组合，polyrhythm 自动发生（12 与 16 的相位漂移就是 HOME 屏画的东西）。
- **同一套参数复用？** 可以：换轨 → 数字行上记下 K/N/ROT → 拧回同一组数 → K4 生成。v1 没做 copy-to-track，觉得烦再加。
- **旋律轨**：完全可用，**与单音/复音无关**——fill 只重写"哪些格 on"（en 位），已存在的 voice（音高/力度/gate/prob）一概不动。bass 轨铺一个 E(16,3) 就是现成的 riff 骨架；和弦 pad 轨铺一个 E(8,3)，和弦触发点变成三连律动，**每格还是整把和弦**（该格有几个 voice 就响几个）。
- 空轨被 fill 时，空 on 步会铺默认 voice：鼓=当前选中的鼓，旋律=C3（#13 待拍板，可能改成"最后弹的音"）。

## 操作面（ARP 页）

- 顶栏 ●LINK = 这轨已和 K/N/ROT 挂钩；K4 右拧=按当前参数重新生成（幂等，铺两次=铺一次），左拧=解冻（steps 留下，meta 清掉，之后手改不会被视为"偏离"——本来就没有 detach 状态）。
- 改 K/N/ROT **立即重铺**，只动 on 位；想要的手改会被下一次拧动覆盖（与步录入覆盖制同构）。
- N 可以比 loop 长：比如 N=12 铺进 16 步的 loop，第 12 格之后没有点——这正是 polyrhythm 的写法之一。

## 什么时候用它，什么时候不用

适合：快速的鼓骨架、polyrhythm 实验、把一条平直的四四底鼓拧成 tresillo 换换味。
不适合：精确的 breakbeat（手绘更快——fill 完逐格手改即可，反正覆盖制没有心理负担）、需要稀疏重音错落的人声类切分。
